Pages in this section are generated from a FastAPI OpenAPI snapshot, so methods, paths, parameters, request bodies, responses, and validation schemas follow the backend implementation. Use search or the sidebar to open an endpoint.

The snapshot covers identity, business membership, products, transactions, education, analysis, receipt imports, and exports available in the backend when the snapshot was created. Regenerate this reference whenever the API contract changes.

The public playground is disabled. Request examples describe data shapes; they are not executable production endpoints from the documentation browser.
