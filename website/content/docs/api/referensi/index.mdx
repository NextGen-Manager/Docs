---
title: Referensi endpoint
description: Endpoint dan schema yang dibangkitkan dari OpenAPI backend SimuMarket AI.
---

Halaman dalam bagian ini dibangkitkan dari snapshot OpenAPI FastAPI, sehingga method, path, parameter, request body, response, dan validation schema mengikuti implementasi backend. Gunakan pencarian atau navigasi sidebar untuk membuka endpoint.

Snapshot mencakup identity, membership usaha, produk, transaksi, edukasi, analysis, receipt import, dan export yang tersedia pada backend saat snapshot dibuat. Regenerasi referensi setiap kali kontrak API berubah.

Playground publik dinonaktifkan. Contoh request digunakan sebagai panduan bentuk data, bukan endpoint produksi yang dapat dieksekusi dari browser dokumentasi.
