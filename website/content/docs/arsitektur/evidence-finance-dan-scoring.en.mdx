## Data and sources

Every market number requires a metric, value, unit, geography, source, observation time, retrieval time, quality, and limitations. Missing evidence remains missing instead of being replaced by an LLM-generated value.

If required evidence is unavailable, a run can finish as `partial`, with affected dimensions marked `not_scorable`.

## Financial calculations

```text
contribution_margin_per_unit = selling_price - variable_cost_per_unit
bep_units_month = fixed_cost_month / contribution_margin_per_unit
monthly_revenue = volume_day * operating_days * selling_price
monthly_operating_profit =
  volume_day * operating_days * contribution_margin_per_unit - fixed_cost_month
payback_months = initial_investment / monthly_operating_profit
```

Money is integer rupiah. Ratios use `Decimal`, and month estimates round upward. A non-positive contribution margin makes break-even and payback undefined. Non-positive operating profit makes payback undefined.

## Launch Readiness Score

```text
LRS = 0.20 * market_saturation
    + 0.25 * demand_potential
    + 0.15 * price_positioning
    + 0.40 * operational_readiness
```

The active rule set is `lrs-v0.2-unvalidated`. A dimension without evidence receives no default. The total score is withheld when a required dimension cannot be scored, preventing silent weight redistribution.

## Evidence confidence

Evidence Confidence assesses source quality, freshness, geographic fit, sample sufficiency, and cross-source consistency. Confidence never secretly raises or lowers the readiness score. Both are displayed with missing evidence and limitations.
