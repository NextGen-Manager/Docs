SimuMarket AI is a Decision Support System for prospective and operating F&B MSMEs in Greater Jakarta. It helps users learn business fundamentals, evaluate a plan before launch, record transactions after launch, and understand operational patterns.

> Analysis results support decisions. They do not guarantee business success.

## Honest status labels

The documentation distinguishes five states:

| Label | Meaning |
|---|---|
| Implemented | Present in the audited code baseline with relevant verification |
| Demo | Uses seed data or an interactive prototype |
| Planned | Designed but not available in the baseline |
| Unavailable | An integration explicitly reports that it is unavailable |
| Unvalidated | Operational, but its parameters or quality are not yet expert-validated |

This documentation publishes only product capabilities, contracts, and limitations relevant to users and developers.

## Documented baseline

Content was verified on 16 August 2026 against frontend commit `ac358ee`, backend commit `2ec6bb8`, and the canonical Docs repository. The live Gemini integration has not been exercised without an API key. Automated tests use the deterministic fake OASIS adapter.

## Rules that do not change

1. The LLM is never the authoritative source of numbers.
2. Every factual number has provenance.
3. Partial failure remains visible as `partial`.
4. Money uses integer Indonesian rupiah.
5. Customer data and raw receipt text are never sent to the LLM provider.
