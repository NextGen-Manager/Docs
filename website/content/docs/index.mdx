SimuMarket AI adalah Decision Support System untuk calon dan pelaku UMKM F&B di Jabodetabek. Sistem membantu pengguna mempelajari dasar usaha, menilai rencana sebelum diluncurkan, mencatat transaksi setelah usaha berjalan, dan memahami pola operasionalnya.

> Hasil analisis adalah alat bantu keputusan, bukan jaminan keberhasilan usaha.

## Kejujuran status

Dokumentasi membedakan lima keadaan:

| Label | Makna |
|---|---|
| Implemented | Tersedia pada produk dan mempunyai verifikasi |
| Demo | Menggunakan seed atau interactive prototype |
| Planned | Sudah dirancang tetapi belum tersedia pada produk |
| Unavailable | Integrasi sengaja menyatakan tidak tersedia |
| Unvalidated | Sudah berjalan, tetapi parameter atau kualitasnya belum tervalidasi pakar |

Dokumentasi ini hanya menerbitkan kemampuan produk, kontrak, dan limitation yang relevan bagi pengguna maupun pengembang.

## Aturan yang tidak berubah

1. LLM tidak menjadi sumber angka otoritatif.
2. Setiap angka faktual mempunyai provenance.
3. Kegagalan parsial tetap ditampilkan sebagai `partial`.
4. Uang menggunakan integer rupiah.
5. Data pelanggan dan teks struk mentah tidak dikirim ke provider LLM.
