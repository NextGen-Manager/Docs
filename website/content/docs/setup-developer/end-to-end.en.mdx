## Prerequisites

- Git.
- Docker Desktop with Docker Compose.
- Node.js 22 for the frontend and documentation site.
- Python 3.11 and `uv` when running the backend outside containers.

Python 3.12 or newer is not used because `camel-oasis 0.2.5` constrains the runtime to Python versions below 3.12.

## Clone the repositories

```bash
git clone https://github.com/NextGen-Manager/SimuMarketAI.git
git clone https://github.com/NextGen-Manager/SimuMarketAI-BE.git
git clone https://github.com/NextGen-Manager/Docs.git
```

Use the team-approved baseline branches. Do not combine frontend and backend revisions with incompatible contracts.

## Complete backend through Docker

```bash
cd SimuMarketAI-BE
docker compose up --build -d
docker compose exec api uv run alembic upgrade head
```

Compose runs the API, worker, beat, PostgreSQL 16, Redis 7, and MinIO. The API is available at `http://localhost:8000`.

```bash
curl http://localhost:8000/v1/health
curl http://localhost:8000/v1/ready
```

Without `GEMINI_API_KEY`, analysis does not fabricate agent output. The live adapter becomes unavailable and a report may finish as `partial`. Tests use a fake adapter that can only be injected in non-protected environments.

## Frontend

```bash
cd SimuMarketAI
npm install
copy .env.example .env.local
npm run dev
```

The frontend is available at `http://localhost:3000`. `BACKEND_URL` is used by the server-side proxy route so the browser calls a same-origin API path.

## Documentation website

Use a different port while the main frontend is running.

```bash
cd Docs/website
npm install
npm run dev -- --port 3001
```

Documentation is available at `http://localhost:3001`.

## Quality checks

Backend:

```bash
uv run ruff check .
uv run ruff format --check .
uv run mypy app
uv run pytest
uv run alembic check
```

Frontend:

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

Website:

```bash
npm run lint
npm run types:check
npm run build
```

## Stopping services

```bash
docker compose down
```

This does not delete volumes. Do not use a volume-removal option unless the local data can be discarded.
